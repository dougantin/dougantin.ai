## What It Is

Design Engineer Tools is a curated directory for the designer-who-ships-code role. It pulls together component references, AI coding tools, visual craft utilities, capture tools, and motion or 3D software into one practical index.

## When To Use It

Use it when you need a fast map of the design-engineer toolkit, especially for UI research, frontend craft, motion references, component sourcing, or figuring out what tools sit adjacent to modern product design work.
