## What It Is

Monid packages a large catalog of third-party tools behind one agent-facing layer, with runtime discovery, inspection, and usage-based access instead of separate vendor integrations.

## When To Use It

Use it when an agent needs broad external actions or data sources on demand, especially for research, enrichment, search, scraping, or operational workflows where integration sprawl would otherwise slow things down.
