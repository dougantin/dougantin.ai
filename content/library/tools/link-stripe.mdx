## What It Is

Link is Stripe's wallet and checkout layer, extended into an agent-payment system where a user can authorize an AI agent to request and complete purchases without exposing raw card numbers or full payment credentials.

## When To Use It

Use it when tracking the payment layer for agent commerce, especially products that need human approval, scoped spend authority, and a cleaner path from agent intent to real-world checkout.
